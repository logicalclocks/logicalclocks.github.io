    How-To Guides#

    Task-focused guides for the Hopsworks UI and APIs, organised by the part of the platform you are working with. For what things are and why, see the Concepts.

    • Start here

      Install the client and authenticate once. Every guide in this section runs from the same session.

      uv venv && source .venv/bin/activate
uv pip install "hopsworks[python]"
hops setup

      Client installation · Create a project · Create a feature group

    Feature Store

    • Feature groups Write features from a DataFrame, validate them, keep statistics.
    • Feature views Read training data, batch data and online feature vectors.
    • Data sources Connect warehouses, object stores and databases as inputs.
    • Feature monitoring Watch statistics over time and compare them to a reference.
    • Transformations and integrations Model-independent transformations, compute engines, external clients.

    MLOps

    • Model registry Register models with metrics, schema and evaluation artifacts.
    • Model serving Deploy a model with a predictor, transformer, logging and autoscaling.
    • Model monitoring Compare inference data against training data on a schedule.
    • Agents Run agent tasks as jobs or serve interactive agents.

    Projects and compute

    • Projects Sign in, create a project, manage members, secrets, keys and alerts.
    • Compute Jupyter, the terminal, jobs, Airflow and Python environments.
    • Analytics SQL over the offline store with Trino, dashboards in Superset.

    Platform

    • Clients Python and Java libraries for your own environment, and the hops CLI.
    • Setup and administration Install on a cloud or on-prem, manage users and operations.
