# Hopsworks 5.0.4 { #hopsworks-5-0-4 }

## Release notes

- Added `hopsworks.service.worker.external.https.nodePort` to pin the node port of the Hopsworks HTTPS service when its `type` is `NodePort`.
- Upgraded OnlineFS to 2.3.2, which pauses and retries online feature store ingestion on temporary RonDB errors, such as during a RonDB upgrade, instead of dropping the rows.
  Set the pause between retries with `onlinefs.configmapOverrides.onlinefssite.service.pauseRetrySleepMs` (default `5000`).

## Breaking changes

There are no breaking changes in this release.

## Migrations

No migration steps are needed.
