# Hopsworks 5.0.5

## Release notes

- Added `rondb.rondb.ndbmtdSequencedRollout.enabled` (default `false`) to roll the RonDB data nodes one node group at a time, on clusters with more than one node group.
- Changed the RonDB startup probe timeouts to 120 minutes for data nodes, from 25, and 20 minutes for MySQL servers, from about 17 (`rondb.rondb.timeoutsMinutes.ndbmtdStartupProbe`, `rondb.rondb.timeoutsMinutes.mysqldStartupProbe`).
- Upgraded RonDB to 26.02.8.

## Breaking changes

There are no breaking changes in this release.

## Migrations

No migration steps are needed.
