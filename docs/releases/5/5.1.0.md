# Hopsworks 5.1.0

Released on 2026-09-24.

## Release notes

- Upgraded OpenSearch to 2.19.5.
- Changed Python apps and all job types to read their default CPU, memory and GPU values from cluster variables.
- Removed Brewer from Hopsworks.

## Breaking changes

- **Action required:** Removed the `hive_default_quota` variable, which set the default Hive database quota for new projects.
  If you set it in your Helm values, remove it before upgrading.

## Migrations

### Before the upgrade

1. Required: take a snapshot of OpenSearch, because the upgrade to OpenSearch 2.19.5 can't be rolled back.

### After the upgrade

1. Optional: check that every OpenSearch pod is ready with `kubectl get pods -n <namespace> -l app=opensearch`.
