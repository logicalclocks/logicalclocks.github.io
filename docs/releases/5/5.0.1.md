# Hopsworks 5.0.1

Released on 2026-07-03.

## Release notes

- Added support for Kubernetes 1.35 and 1.36.
- Added an option to expose the Hive Metastore outside of Kubernetes.
- Added an option to set `s3ForcePathStyle` on the Velero backup storage location.
- Fixed Superset returning 302 redirects when it runs behind a reverse proxy.
- Upgraded the Superset MySQL database to 8.4.10.

## Breaking changes

There are no breaking changes in this release.

## Migrations

No migration steps are needed.
