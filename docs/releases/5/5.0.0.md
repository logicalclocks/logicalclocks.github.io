# Hopsworks 5.0.0

Released on 2026-06-11.

## Release notes

- Added mounting of shared datasets with hopsfsmount.
- Added tolerations for user workloads such as Jupyter, jobs and deployments.
- Added authentication credentials for PyPI, Conda and apt proxies.
- Added multi-tenant support for the remote shuffle service webhook and controller.

## Breaking changes

There are no breaking changes in this release.

## Migrations

No migration steps are needed.
