# Releases

Each Hopsworks minor version has a page with the release notes of its releases, newest first.
A release lists what changed, the configuration changes, the breaking changes, the deprecations and the upgraded components since the release named under its title: the previous release of its minor version, or for an X.Y.0, the previous X.Y.0.
Each change is listed once, under the release that first shipped it.

To upgrade, move one minor version at a time.
Act on the breaking changes of every release after yours, up to the one you upgrade to, and follow the upgrade steps of each X.Y.0 you move to.
