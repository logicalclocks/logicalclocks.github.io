# Releases

Each minor version has one page, with its releases newest first.
A patch release lists what changed since the previous release of its minor version.
A new minor version (X.Y.0) lists everything since the previous X.Y.0, and marks what already shipped in a patch release.

When you upgrade, read the breaking changes of every release between yours and the one you upgrade to, and follow the upgrade steps of each X.Y.0 on the way.
