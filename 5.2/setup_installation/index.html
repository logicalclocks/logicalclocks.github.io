    Setup and Administration#

    Hopsworks runs on Kubernetes, on a cloud provider or on your own hardware. This section covers installing the platform and administering it afterwards. For the client libraries, see the Client Installation guide.

    • Start here

      Pick your environment and follow its getting started guide. Each one takes you from an empty account to a running cluster with a first project.

      AWS · Azure · GCP · On-prem

    Install

    • AWS, Azure, GCP Managed Kubernetes on each cloud, with the storage and network the cluster needs.
    • On-prem Your own Kubernetes, optionally with an external Kafka cluster.
    • Cluster configuration Configuration variables, with the full reference and build performance notes.

    Users and access

    • Users and projects Approve users, assign roles, manage projects and quotas.
    • Authentication OAuth2 identity providers, LDAP and Kerberos, with project mapping.
    • IAM role chaining Let projects assume AWS roles.

    Operate

    • Monitoring Service dashboards, exported metrics and service logs.
    • High availability and disaster recovery Replicated services and backup, restore procedures.
    • Audit and operations Access audit logs, service operations, search index.
    • Alerts, Trino, Superset Cluster-wide alert receivers and the analytics services.
